# Mask

## 개 요

- 외부 LLM/AI 서비스 사용 시 민감한 단어(Terms)를 가리는(Mask) 도구입니다. 

- 가린 채로 질문하고, 돌아온 답변은 원래 단어로 복구(Restore)해 줍니다. 입력한 내용은 이 브라우저 내에서만 임시 저장되며, 외부로 전송되지 않습니다.

## 사용 방법

1. 화면 우측 상단의 Terms 버튼을 눌러 가릴 단어를 등록합니다.
2. 원문을 붙여넣고 Mask 버튼을 누른 뒤, 가려진 글을 복사해 LLM에 질의합니다.
3. 화면 좌측 상단의 Restore를 눌러 LLM 답변을 붙여넣고 Restore 버튼을 누르면 원래 단어로 돌아옵니다.
